## 🌟 Overview

**EGER** (from the Afaan Oromoo word for *"The Future"*) bridges the gap between local secondary exam excellence and world-class international higher education admissions.

### 🏛️ The Three Pillars

1. **National Entrance Exam Vault**:
   - Comprehensive Grade 9–12 foundation blueprints (Natural & Social Sciences).
   - 600+ Super-Score exam techniques: The 3-Pass Method, distractor avoidance, formula binders.
   - Interactive Ethiopian University Placement Predictor (AAU, ASTU, AASTU, Jimma, Hawassa, Gondar).
   - Curated resources (*Dan Academy*, *Ethiopian Education*, *Extreme Series*, *Aster Nega*).

2. **Digital SAT (DSAT) 1500+ Mastery**:
   - Adaptive module routing tactics (Module 1 vs Hard Module 2).
   - Complete Desmos Calculator Bible (linear/quadratic regression, systems of equations, sliders).
   - Reading & Writing punctuation laws (Erica Meltzer grammar rules, transition trees, 10-second rhetorical synthesis scan).

3. **Global Full-Ride Scholarships & College Applications**:
   - Step-by-step Common Application & CSS Profile/ISFAA financial aid guides.
   - Need-Blind vs. Need-Aware institutions meeting 100% demonstrated need (Harvard, MIT, Yale, Amherst, Bowdoin, Dartmouth, Berea, NYU Abu Dhabi, MasterCard Foundation).
   - Extracurricular Activities (ECs) Spike Builder (Tier 1–4 framework & 150-char action formulas).
   - Compelling Personal Statements ("Show, Don't Tell" methodology, Narrative vs. Montage structures).
   - Competitive summer opportunities: Yale Young Global Scholars (YYGS), RISE Global Winners.

## 🚀 Running Locally

No dependencies required! Simply open `index.html` in any web browser, or serve locally with Python:

```bash
python -m http.server 8080
```
Then visit [http://localhost:8080/](http://localhost:8080/).
